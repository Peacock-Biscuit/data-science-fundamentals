# Machine Learning

Implementations and projects covering core machine learning theory 
and application — from foundational algorithms to applied systems.

## Featured Project

**Credit Card Fraud Detection System**  
End-to-end ML project applying unsupervised and supervised learning 
to the IEEE-CIS Fraud Detection dataset. Covers data preprocessing, 
feature engineering, clustering analysis, and classification model 
evaluation.  
[View project site](https://peacock-biscuit.github.io/CS7641-Machine-Learning-Project/)

## Topics Covered

- Supervised Learning — classification, regression, decision trees, 
  SVMs, neural networks
- Unsupervised Learning — clustering, dimensionality reduction
- Model evaluation and selection
- Maximum likelihood estimation
- Information theory — entropy, mutual information
- Linear algebra foundations for ML — SVD, eigendecomposition
- Probabilistic modeling — Bayesian inference, MLE

## Libraries Used

scikit-learn · NumPy · pandas · matplotlib · PyTorch
