# Bayesian Statistics 

## Course Overview
This repository contains coursework and projects for ISyE6420 Bayesian Statistics, a comprehensive graduate-level course covering Bayesian inference, modeling, and applications.

## Course Topics

### Fundamentals
- Bayesian vs. Frequentist Approaches
- Prior Selection and Elicitation
- Posterior Inference and Credible Intervals
- Likelihood and Bayesian Model Building

### Advanced Methods
- Hierarchical Models
- Mixture Models
- Markov Chain Monte Carlo (MCMC)
- Gibbs Sampling and Metropolis-Hastings Algorithm
- Variational Inference

### Causal Inference
- Causal Graphical Models and DAGs (Directed Acyclic Graphs)
- Potential Outcomes Framework
- Identification Assumptions (Unconfoundedness, Overlap, SUTVA)
- Causal Effect Estimation (ATE, CATE)
- Instrumental Variables and Causal Inference
- Bayesian Approaches to Causal Discovery
- Sensitivity Analysis and Unmeasured Confounding
- Causal Mediation Analysis

### Applications & Extensions
- Time Series and State-Space Models
- Spatiotemporal Modeling
- Model Comparison and Selection (Bayes Factors, WAIC, LOO-CV)
- Bayesian Nonparametrics

## Key Learnings
- Strong foundation in Bayesian theory and practical implementation
- Proficiency with probabilistic programming and MCMC methods
- Understanding of modern causal inference techniques in a Bayesian framework
- Application of Bayesian methods to complex real-world problems

## Resources & Tools
- **Software**: R, Stan, Python (PyMC, Arviz)
- **References**: Gelman et al. (BDA3), Pearl (Causality), Angrist & Pischke (Mostly Harmless Econometrics)
